Шпаргалка по HTML для лендинга

Все теги, которые нужны для сайта «Лесопил». Тег пишется в угловых скобках. Почти у всех тегов есть открывающий <p> и закрывающий </p>, а содержимое стоит между ними.

1. Каркас страницы

<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>ООО «Лесопил»</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  ... всё, что видно на странице ...
</body>
</html>
<!DOCTYPE html>Первая строка любой страницы: «это HTML».
<html lang="ru">Вся страница. lang="ru" значит, что язык русский.
<head>Служебная часть, на странице не видна.
<meta charset="UTF-8">Кодировка. Без неё русские буквы превращаются в «кракозябры».
<title>Название вкладки в браузере.
<link rel="stylesheet" href="style.css">Подключает файл со стилями CSS.
<body>Всё, что видно на странице.
<!-- текст -->Комментарий. Браузер его не показывает.

2. Крупные блоки страницы

<header>Шапка: название и меню.
<nav>Меню, внутри ссылки.
<section>Раздел страницы: «О компании», «Товары», «Контакты».
<footer>Подвал в самом низу.
<div>Простой блок-коробка, чтобы сгруппировать элементы. Например, одна карточка товара.

Сами по себе эти теги никак не выглядят. Внешний вид им задаёт CSS.

3. Текст

<h1>Заголовок</h1>Главный заголовок. На странице один.
<h2>Заголовок раздела.
<h3>Заголовок поменьше, например название товара.
<p>Абзац</p>Абзац текста.
<b>жирный</b>Жирный текст внутри абзаца.

4. Список

<ul>
  <li>Своё производство</li>
  <li>Доставка по городу</li>
</ul>

<ul> это список с точками, <li> один пункт. Пункты пишутся только внутри <ul>.

5. Картинка

<img src="brus.jpg" alt="Брус">
srcИмя файла картинки. Файл лежит в той же папке, что и index.html.
altТекст, который видно, если картинка не загрузилась.

У <img> нет закрывающего тега.

6. Ссылки

<a href="#about">О компании</a>К разделу с id="about" на этой же странице.
<a href="#top">Наверх</a>К элементу с id="top", обычно это шапка.
<a href="about.html">На другую страницу сайта.
<a href="about.html#team">На другую страницу и сразу к её разделу.
<a href="#">Ссылка-пустышка, никуда не ведёт. Её нужно заменить.

Решётка # в ссылке значит «найди элемент с таким id». В самом id решётку не пишут.

7. Атрибуты id и class

<section id="about">id это уникальное имя элемента. На странице встречается только один раз. К нему ведут ссылки #about.
<div class="card">class это имя группы. Можно дать многим элементам, и все они получат одинаковый стиль .card из CSS.
<section id="products" class="light">У элемента может быть и id, и class одновременно.

Имена id и классов пишем латиницей, без пробелов: about, no-photo.

8. Карточка товара целиком

<div class="card">
  <img src="doska.jpg" alt="Доска">
  <h3>Доска обрезная</h3>
  <p>Ровная доска без коры, длина 6 метров.</p>
  <p class="price">от 14 000 ₽ за м³</p>
</div>

9. Частые ошибки

Меню никуда не ведётВ href забыли решётку или имя не совпадает с id: href="#About" и id="about" это разные имена.
Картинки не видноИмя файла в src написано с ошибкой или файл лежит в другой папке.
Стили не работаютНе подключён style.css или в class опечатка.
Вся страница «поехала»Забыли закрыть тег, например </div> или </section>.
Вместо букв «кракозябры»Нет строки <meta charset="UTF-8">.
