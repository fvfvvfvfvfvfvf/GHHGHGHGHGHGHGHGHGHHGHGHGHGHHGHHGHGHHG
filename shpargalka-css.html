Шпаргалка по CSS для лендинга

Все свойства, которые нужны для сайта «Лесопил». CSS пишем в файле style.css, который подключён в <head> строкой <link rel="stylesheet" href="style.css">.

1. Как устроено правило

селектор {
  свойство: значение;
  свойство: значение;
}

/* пример */
h1 {
  color: white;      /* цвет текста */
  font-size: 44px;   /* размер */
}

Селектор говорит, к чему применить стиль. В фигурных скобках написано, как это должно выглядеть. После каждого свойства ставится точка с запятой. /* ... */ это комментарий.

2. Селекторы: к чему применить

body { }По тегу: все элементы <body>.
.card { }По классу: все элементы с class="card". Точка перед именем.
#about { }По id: элемент с id="about". Решётка перед именем.
nav a { }Вложенные: ссылки, которые находятся внутри <nav>.
.card img { }Картинки внутри карточек.
.hero h1 { }Заголовок h1 внутри блока .hero.

3. Цвета

Цвет пишем словом по-английски, маленькими буквами и без пробелов.

color: black;Цвет текста.
background: wheat;Цвет фона.

4. Текст

font-family: Arial, sans-serif;Шрифт.
font-size: 18px;Размер текста.
font-weight: bold;Жирный текст.
line-height: 1.5;Расстояние между строками (1.5 значит в полтора раза больше обычного).
text-align: center;Выравнивание: left, center, right.
text-decoration: none;Убрать подчёркивание у ссылки.
text-shadow: 0 0 10px black;Тень у текста, чтобы его было видно на фото.

5. Отступы, рамки и размеры

padding: 20px;Отступ внутри элемента, от края до содержимого.
padding: 15px 40px;Два числа: сверху и снизу 15px, слева и справа 40px.
margin: 0;Отступ снаружи, от соседних элементов. У body ставим 0, чтобы убрать белую рамку.
margin-left: 20px;Внешний отступ только слева. Есть ещё -right, -top, -bottom.
border: 1px solid lightgray;Рамка: толщина, тип линии, цвет.
border-radius: 8px;Скруглённые углы.
width: 100%;Ширина. 100% значит на всю ширину родителя (например, картинка на всю карточку).
margin  →  [ border  →  padding  →  содержимое ]
снаружи      рамка      внутри

6. Картинка на фоне

.hero {
  background: url("doska.jpg");  /* картинка на фоне */
  background-size: cover;        /* растянуть на весь блок */
}

7. Расположение: flex

display: flex;Ставит всё, что лежит внутри элемента, в один ряд.
justify-content: space-between;Разносит элементы по краям: первый слева, последний справа. Так в шапке название слева, меню справа.
gap: 20px;Расстояние между элементами в ряду.
flex: 1;Пишем у элементов внутри ряда. Все становятся одинаковой ширины.
display: inline-block;Для ссылки-кнопки: элемент стоит в строке, но отступы padding работают правильно.
.cards { display: flex; gap: 20px; }   /* ряд карточек */
.card  { flex: 1; }                    /* одинаковая ширина */

8. Шапка и прокрутка

position: sticky;
top: 0;		Шапка «прилипает» к верху окна и не уезжает при прокрутке. Нужны обе строки.
html { scroll-behavior: smooth; }Плавная прокрутка при клике на пункт меню.
section { scroll-margin-top: 50px; }Отступ сверху при переходе к разделу, чтобы шапка не закрывала заголовок.

9. Частые ошибки

Стиль не применяетсяОпечатка в имени класса, или забыли точку: card { } вместо .card { }.
Не работает всё после какой-то строкиЗабыли ; после свойства или } в конце правила.
Фон-картинки не видноОшибка в имени файла внутри url("...").
Шапка всё равно уезжаетНаписали position: sticky;, но забыли top: 0;.
Карточки не встают в рядdisplay: flex; нужно писать у родителя (.cards), а не у каждой карточки.
Число без единицpadding: 20; не сработает. Нужно 20px.
